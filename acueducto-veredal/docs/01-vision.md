# Visión del producto

## Nombre tentativo
Acueducto Veredal

## Visión
Construir una aplicación web para administrar uno o varios acueductos veredales, centrando la operación en el derecho de agua como unidad principal de negocio, permitiendo controlar titulares, transferencias, facturación, cartera, gastos, cierres mensuales y trazabilidad operativa.

## Problema a resolver
La administración manual o dispersa del acueducto genera dificultades para:

- saber cuántos derechos existen y a quién pertenecen
- facturar correctamente por cada derecho de agua
- controlar cartera vencida
- registrar pagos y emitir soportes
- llevar control de gastos
- hacer cierres mensuales transparentes
- conservar trazabilidad cuando un derecho cambia de dueño o de inmueble asociado
- reutilizar la solución para más de un acueducto veredal

## Objetivo del sistema
Ofrecer una plataforma simple y trazable para operar el acueducto, permitiendo que la administración se haga de forma centralizada, segura y preparada para escalar a pagos electrónicos y atención multicanal.

## Principios de diseño del producto

1. El derecho de agua es la entidad principal del negocio.
2. La persona es una entidad de consulta y titularidad, no la unidad primaria de cobro.
3. Toda factura mensual se genera por derecho de agua.
4. Toda cartera se controla por derecho de agua, con vista consolidada por persona.
5. Un derecho puede transferirse sin perder continuidad histórica.
6. La aplicación debe funcionar para múltiples acueductos veredales.
7. La interfaz debe ser sencilla para usuarios administrativos no técnicos.
